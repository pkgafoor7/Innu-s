# Innu's Foods — Traditional Taste of Kerala (Website Package)

## Included Files
- `index.html`: Complete, standalone responsive storefront with product catalog, category filters, shopping basket, and direct WhatsApp checkout.

## How to Host Online for Free
1. Extract this ZIP archive so you have the `innus-foods` folder (or `index.html` file).
2. Visit **https://drop.netlify.com/** (or **Vercel** / **GitHub Pages** / **Cloudflare Pages**).
3. Drag and drop the extracted folder onto the page to publish your live website immediately.

## Setting Your Business WhatsApp Number
- **Quick method:** Open your live site, click **Store WhatsApp (Edit)** in the top bar, and enter your number with country code (e.g., `966501234567`).
- **Permanent default:** Open `index.html` in any text editor (like Notepad or VS Code), search for `966500000000`, and replace it with your WhatsApp business number (digits only, with country code).
